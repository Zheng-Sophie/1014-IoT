## Dataset

**50_Startups.csv** — Kaggle dataset with 50 startup company records.

| Column | Type | Description |
|---|---|---|
| R&D Spend | float | Research & Development expenditure |
| Administration | float | Administrative expenditure |
| Marketing Spend | float | Marketing expenditure |
| State | string | US state: California / Florida / New York |
| Profit | float | **Target variable** |

- No missing values, no duplicate rows
- Strong correlation between R&D Spend and Profit (r = 0.973)

---

## CRISP-DM Methodology

| Phase | Description |
|---|---|
| 1. Business Understanding | Predict startup Profit from 4 input features |
| 2. Data Understanding | EDA: shape, types, missing values, correlations |
| 3. Data Preparation | Drop duplicates, train/test split (80/20), preprocessing pipeline |
| 4. Modeling | 5 feature selection schemes × Linear Regression |
| 5. Evaluation | Nested cross-validation (PMSE, R²), hold-out test metrics |
| 6. Deployment | Model serialized via `joblib` |

---

## Feature Selection Schemes

Five schemes are compared at each feature count k = 1, 2, 3, 4:

| Scheme | Method |
|---|---|
| **Exhaustive** | Try all feature combinations, pick lowest CV PMSE |
| **RFE** | Recursive Feature Elimination using LinearRegression |
| **SFS** | Sequential Forward Selection (greedy, add one at a time) |
| **Lasso** | LassoCV ranks features by coefficient magnitude |
| **SBS** | Sequential Backward Selection (greedy, remove one at a time) |

Preprocessing pipeline per subset:
- Numeric features → `SimpleImputer(mean)` + `StandardScaler`
- Categorical (`State`) → `SimpleImputer(most_frequent)` + `OneHotEncoder` (drop first)

## Results

### Nested CV — Best at Each Feature Count (main_2.py)

| k | Best Features | PMSE | R² |
|---|---|---|---|
| 1 | R&D Spend | 98,880,571 | 0.9426 |
| 2 | R&D Spend, Marketing Spend | 93,751,894 | 0.9455 |
| **3** | **R&D Spend, Administration, Marketing Spend** | **91,846,901** | **0.9466** |
| 4 | All features (incl. State) | 99,836,231 | 0.9420 |

> All five schemes agreed: **k=3 (excluding State) is optimal**.
